# Codebase client UI reference

This folder archives a design experiment created for `building-schedule` while studying the layout and interaction patterns of Pixelcave Codebase.

## Purpose
- Preserve the design experiment separately from the production application.
- Keep reference-oriented UI work out of the public production source of truth.
- Reuse only general layout and interaction principles when useful.

## Files
- `index.html` — reference screen structure
- `style.css` — reference visual system
- `app.js` — prototype interactions and schedule behavior

## Important
This is a reference/prototype implementation. Do not treat it as the production source of truth. Do not add third-party commercial source code or proprietary assets to this repository.
